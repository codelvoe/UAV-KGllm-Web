# 建议截图清单

1. 登录页：采集系统名称、账号密码输入框和登录按钮。
2. 系统首页：采集轨迹数、图谱节点数、图谱边数、F1/FAR 图表和功能入口。
3. 多模态数据管理：采集模态筛选、数据表格和详情区域。
4. 轨迹证据管理：采集轨迹摘要表、特征雷达图和时间线。
5. 知识图谱可视化：采集图谱画布、筛选条件和节点属性面板。
6. KG 融合候选分析：采集候选列表、KG score 排名图和得分组成雷达图。
7. 大模型智能研判：采集候选证据、KG 分数和大模型裁决结果。
8. 大模型对话助手：采集历史对话、快捷问题和证据引用。
9. 性能评估与运行分析：采集检测性能表、F1/FAR 图和鲁棒性表。
10. YOLO目标探测：采集输入区、检测画面、检测结果和智能研判结论。
11. 系统设置：采集数据目录、大模型接口、Neo4j 连接和报告格式配置。
