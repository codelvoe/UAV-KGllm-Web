# 软件功能说明

## 软件名称

基于知识图谱与大模型的无人机多源感知融合分析系统 V1.0

## 软件概述

本软件面向低空无人机探测与多源感知融合分析场景，提供雷达、频谱、光电识别、光电状态、隐藏标签等多源数据管理能力，支持知识图谱可视化、KG 融合候选分析、大模型辅助研判、自然语言问答、性能结果对比和研判报告生成。

系统采用前后端分离架构，前端提供完整 Web 页面和交互流程，后端提供数据读取、接口服务、候选分析、本地规则研判和报告生成能力。系统可读取本地 JSON、JSONL、CSV 数据，也可通过可选配置连接 Neo4j 数据库。

## 主要功能

1. 多模态感知数据管理  
   支持 radar、spectrum、recognize、pho_status、decrypt 等数据的列表管理、筛选、搜索和详情查看。

2. 轨迹证据管理与查询  
   支持 radar tracks、spectrum tracks、recognize tracks、decrypt label tracks 的轨迹摘要管理，包含时间范围、点数、方位、距离、高度、速度、信号强度、置信度和 SNR 等特征。

3. 知识图谱可视化分析  
   支持节点和边的图谱可视化，支持节点类型筛选、模态筛选、轨迹 ID 搜索、节点点击查看属性和邻居关系。

4. KG 融合候选生成与分析  
   汇总 KG Fusion 生成的候选目标，包括时间重叠、方位差、KG 分数、候选排名、冲突标记和裁决状态，并提供得分组成图表。

5. 大模型智能研判  
   面向候选目标提供大模型辅助裁决，输出 confirm、reject 或 uncertain，给出风险等级、研判理由、证据引用和处置建议。

6. 大模型对话问答  
   支持围绕系统数据、知识图谱、融合候选和实验指标进行自然语言问答，并提供快捷问题模板。

7. 实验结果对比分析  
   汇总 Radar-only、KG Fusion、KG-Heuristic、KG+LLM Agent 等方法在不同场景下的 Precision、Recall、F1、FAR、Token 成本、端到端延迟和鲁棒性指标。

8. 研判报告生成  
   支持选择候选目标、研判结果和实验指标生成 Markdown 或 HTML 研判报告。

9. 系统参数配置  
   支持配置数据目录、本地规则模式开关、大模型接口地址、Top-K 候选数量、图谱节点数量、Neo4j 连接参数和报告导出格式。

## 软件特点

1. 支持雷达、频谱、光电识别、设备状态等多源数据管理。
2. 支持知识图谱节点和边的可视化。
3. 支持候选目标融合分析和评分拆解。
4. 支持大模型辅助研判和自然语言问答。
5. 支持检测性能指标和系统成本指标分析。
6. 支持报告生成，便于形成研判结果。
7. 支持真实数据优先读取和本地运行数据自动生成，便于系统部署和运行检查。
